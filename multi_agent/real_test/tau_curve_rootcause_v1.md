# τ_ego 曲线非单调根因分析 (tau_curve_rootcause_v1)

> 数据分析 agent + 主控核, 2026-06-12。只读分析, 未改任何原始数据。
> 数据源: `/tmp/strong_sweep.csv`(H800 te50-400, 54路) + `/tmp/te500_full.csv`(H800 te500, 105路) + 4090 te0/te219 逐路 `results.json` + `tau_curve_sensitive_routes_v1.csv`(选route依据) + `route_scenario_classification_v1.csv`。
> H800 te0/te219 基线尚未出(`/data/jichengzhi_v2x/baseline_summary.csv`), 故假设1的最终判决待补; 但已可用强间接证据先定主因。

## TL;DR (主因排序)

非单调的根因, 按贡献从大到小:

1. **【主因】平台混淆 (假设1) — 证实(强间接证据)。** te0/te219 是 4090, te50-500 是 H800。曲线里 "te0/te219 高(75-85) → te50 悬崖跌到 35" 这一段不是延迟效应, 是 4090→H800 的平台跳变。直接证据: 同一批 54 路线在 4090 上从 te0→te219(延迟+219ms)DS 几乎不动(大量路线 te0=te219=100), 一过到 H800 才崩。这一步贡献了曲线里几乎全部的"动态范围"。

2. **【次主因】碰撞饱和 / 地板效应 (假设2) — 证实。** 在纯 H800 区间(te50-500), 54 条强敏感路线每一档碰撞率 ≈98%(te50: 53/54 撞)。DS 被钉在"撞了一次"的低分地板上, 没有动态范围, 档间差全是噪声。

3. **【第三】筛选标准污染 (假设3) — 证实(铁证)。** `tau_curve_sensitive_routes_v1.csv` 的 `sensitivity = delta_0to500 = te0_DS(4090) − te500_DS(H800)`。这个 Δ 按定义就是平台差, 不是延迟敏感度。所以这 54 条是"4090 与 H800 最分歧"的路线, 不是"对延迟最敏感"的路线 —— 选样本的指标本身把平台差当成了信号。

4. **【放大器, 非独立根因】n=1 洗牌噪声 (假设4) — 证实但次要。** 每路每档单跑, 在 ~98% 都撞的饱和区里, 单次"撞早/撞晚"的随机性就是档间起伏的来源。它是在前 2/3 已经压平动态范围之后, 把残余平地"抖"成假的非单调; 不是第一性原因。

**一句话**: 这条曲线非单调, 主要不是因为"延迟对驾驶的影响本来就非单调", 而是因为横轴混了两台机器(4090 te0/te219 + H800 te50-500), 纵轴又被 98% 碰撞饱和压成地板, 且选路线的指标本身就是平台差。三者叠加, 真实的延迟信号(若存在)被埋没。

## 假设逐条判决

### 假设1 — 平台混淆: 证实(强间接证据, 最终判决待 H800 基线)

正向证据(支持"是平台伪影"): 4090 上延迟拉满 219ms 也不掉分。逐路读 results.json 实测:

| route | 4090 te0 | 4090 te219 | H800 te50-400 区间 |
|---|---|---|---|
| 6   | 100 | 37.8(blocked) | 6.5–36 (全撞) |
| 314 | 100 | 36 | ~10.6 (全撞) |
| 26  | 100 | 100 | 1.0–16.3 (全撞) |
| 303 | 100 | 100 | 20–65 |
| 2   | 100 | 60 | 25–65 |
| 113 | 100 | 100 | 58.8 (全撞) |
| 22  | 80  | 80 | 7–12 (全撞) |
| 23  | 60  | 36 | 3–8 (全撞) |

关键: route 26/303/113 在 4090 上 te0=te219=100(延迟从 0 加到 219ms, DS 纹丝不动), 但一换到 H800 就崩到个位数~65。⇒ 把 75-85 → 35 的"te0→te50 悬崖"归因于延迟是错的, 那是 4090→H800 跳变。

设计文档 §1 的 te0/te219 交叉验证表(两点都在 4090)也显示延迟效应小: 高强度 Δ=-9.0、中 -21.0、低 -12.5 —— 纯 4090 内延迟 0→219ms 对 DS 影响只有个位~20 分量级, 远小于 4090(75-85)→H800(35) 的 ~40-50 分跳变。

反向/封口条件:
- 若 H800 te0 ≈84(高) → te0(H800)→te50(H800) 是真悬崖 → 平台不是主因, 改判"50ms 即延迟悬崖"。
- 若 H800 te0 ≈35(低) → 坐实平台混淆是主因。
- 目前 4090 内 te0=te219 不掉分强烈预示后者, 但必须用 H800 te0/te219 实测封口。

### 假设2 — 碰撞饱和(地板效应): 证实

逐档 54 条 collided=1 比例(strong_sweep.csv): te50 53/54≈98.1%(仅 r154 未撞) / te100 ~89% / te150 ~93% / te200 ~87% / te300 ~91% / te400 ~98%(7条NA) / te500 54条全撞。te50 就已 98% 碰撞 → 这 54 条在任何 ≥50ms 延迟下基本全撞, DS 一上来就被钉碰撞地板(大量 <20), 动态范围 ≈0, 档间均值上下抖动只来自"撞得多惨"的 penalty 随机性。

### 假设3 — 筛选标准污染: 证实(铁证)

`tau_curve_sensitive_routes_v1.csv`: sensitivity 由 `delta_0to500 = te0_DS(4090) − te500_DS(H800)` 决定。该 Δ = 平台差+延迟差混合且平台差占大头。排序选出的 54 条 = "4090跑得好+H800跑得差"分歧最大的路线, 而非"对延迟最敏感"的路线。表里 te0/te219 两列都在 4090, 对大量强路线 te0=te219=100(延迟+219ms 零影响), 它们被选中完全因为 te500(H800)低=平台差。

### 假设4 — n=1 洗牌噪声: 证实但次要(放大器)

纯 H800 区间单路非单调随处可见(无平台混淆): r6 te50-400 = 10.8/6.48/21.6/21.6/36/12.96; r303 = 20.1/65/39/65/65/39; r161 = 15.6/1.34/4.92/17.3/4.9/1.07。严格单调下降路线占比 ≈0(连 r26 反是单调上升)。⇒ 纯 H800 区间内根本不存在 graded 延迟退化信号, 全是饱和地板上的随机起伏。加 n 只平噪声, 不造信号。

## te219 异常解释 (4090=74.6 高于两侧 H800 te200/te300=44)

纯平台 + 库口径不一致, 不是延迟反转。te219=4090(4090红利偏高) vs te200/te300=H800(饱和库~44); 且 te219 是全105路均值(含大量简单高分路线), te200/300 是54饱和路。二者差 = 平台差 + 库不同, 与延迟单调性无关。

## 要得到有效单调曲线, 必须怎么做 (按优先级)

1. **【P0 解假设1+3】全程同一台机器。** 整条曲线(τ=0/50/.../500)全部在 H800 重跑, 含 te0/te219。绝不能拼 4090+H800。baseline_summary.csv 出来后第一件事就是替换 4090 那两点, 重画纯 H800 9 点曲线。
2. **【P0 解假设3】换无偏选样, 丢弃 delta_0to500。** 用 route_scenario_classification 的场景类型/强度先验选库, 冻结后所有 τ 档跑同一库。禁用任何含跨平台 Δ 的筛选。
3. **【P0 解假设2】选"中强度/有退化空间"的库避开饱和。** 当前 54 条 te50 即 98% 撞光=地板。设计文档 §1 已发现中强度是黄金区(baseline 高、有退化空间、Δ 最大)。主曲线用中强度 39 条(或全 105 除 r112)。判据: 选库后 te0(H800)碰撞率应 <50% 才有往下掉余量。
4. **【P1 解假设4】n≥3(建议5)重复, 报 mean±95%CI。** 判据: 相邻档差异 > CI 才算真信号。
5. **【P1 机理区分】"延迟悬崖" vs "渐变退化"分开讲。** 延迟效应可能本是阈值型(某 τ 后晚刹车→撞行人)而非线性 graded。先把平台混淆+饱和清掉才能判断"非单调"是真信号还是伪影。
6. **【P2 口径统一】每条曲线标清: 哪台机器、哪个冻结库(route列表+版本)、n、DS 来自 ego_vehicle_0/results.json 的 global_record.scores.score_composed(顶层 results.json 的 global_record 为空, 别误用)。**

## 诚实的反向 / 不确定项

- 假设1 尚未铁证封口: 没有 H800 te0/te219, "te0→te50 是平台跳变"是强间接推断。必须等 baseline_summary.csv。
- 延迟效应方向是对的: 纯 4090 te0→te219 三个强度档都 te219<te0(延迟确实伤驾驶), 只是量级小(≤21分)且被平台/饱和淹没。"延迟无效"是错结论 —— 是"当前实验设计测不出它"。
- te400 有 7 条 NA(30,162,163,12,322,151,7 跑挂), 样本缩到 47, 也是工程性噪声源。
