## 1. 完整框架工作流

理论基座 = ALT(内外环交替) + CHaNAS(进化外环) + AutoTVM(schedule 内环 + rank cost model)。目标: **导入网络+硬件 → 输出该硬件 measured Pareto 前沿(AP×latency×energy)**。

```
[Stage1 空间构造] 导入网络 + 目标硬件
  ├─ 硬件能力扫描 H → 可部署性 ψ_hw (如 int8 是否可 build)
  ├─ DepGraph 计算图分区 G → N 个剪枝/量化分区 + 结构合法性 ψ_group (grouped-conv 整除等)
  └─ 输出合法软件空间 Θ_sw = ∏_分区 (宽度档 × 精度档), 经 ψ_hw ∩ ψ_group 过滤
        (stage1_bridge.py 自动推 SpaceSpec + 可分离性)  —— 空间是分区数上的指数, 见 §2
        ↓
[外层 cost model 冷启动] per-(model,hw) LightGBM, 用样本真测点训练
  ├─ f_lat:    配置→log(lat) 值头 + lambdarank 序头   (标签=整网真测 latency, 如 original60)
  ├─ f_energy: 配置→log(energy) 值头 + rank 序头        (标签=整网真测 energy)
  └─ f_ΔAP:    配置→ΔAP 残差 (仅排序粗筛)              (标签=finetune 后 1789 真测锚点)
  + feasibility 二分类 (build_success / AP_crash)
  (surrogate 就是用来"不必真测指数级全空间"的手段)
        ↓
[外环 NSGA-II 多目标搜索] 目标 = (AP, latency, energy) 三维 Pareto
  每代候选 x=(p,q):
     ├─ f_lat / f_energy 预测 (整配置直接回归, 无跨块相加)
     ├─ f_ΔAP 残差排序 + 代理粗筛 → 剔明显崩塌点
     └─ NSGA-II 非支配排序 + 拥挤度 → 下一代
        ↓
[SMBO / 主动学习在线闭环] (AutoTVM 式)
  每代/每轮:
     选 Top-K (前沿邻域 × 高不确定度, ε-greedy) 候选 —— 都是未测的新联合配置
     → 真测: 内层 MetaSchedule 真调优该配置整网 + 实测 (lat,energy); AP 走 finetune+1789 真测
     → 证据回灌重训外层 cost model
     → 下一代 (同时精炼 Pareto 前沿 + cost model)
        ↓
[阶段三 收尾] Pareto 前沿 Top-K 整网真测复核 (surrogate 只是搜索加速器, 非真值替代)
  + 三臂消融 Gap1: S0(默认调度) / S1(串行 先剪再调) / S2(联合 P×Q×S) 证联合价值
  → 论文表图 (measured Pareto)
```

### 关键机制
- **分层根因**: 内层同数量级(µs, AST 特征) vs 外层跨数量级(prune 0→90% + FP32→INT8, 延迟 span 数量级)。合一会崩(lgb_v6 教训)→ 分层 + 外层 rank loss。
- **防指数爆炸 = surrogate + SMBO**(不是加性 LUT): 指数级 Θ_sw 不可能全测 → 用样本训 surrogate 预测全空间, SMBO 只真测每轮 Top-K, 证据回灌迭代。
- **latency/energy 用 rank+log, AP 用残差**: latency/energy span 大信号强; AP 配置效应仅 ~0.04 近任务上限(高原区量化惩罚已实测=噪声级)→ AP 只配排序。
- **内层 schedule**: 每个被真测的配置由 TVM MetaSchedule(evolutionary_search + xgb rank)调最优 schedule; 结果按配置缓存复用; **配置间不做相加组合**。
- **AP 四层级联降 finetune 成本**: ΔAP残差排序 → 廉价代理剔崩塌 → 早停 finetune 粗排 → 收敛 finetune 只给最终前沿锚点。

## 2. 搜索空间规模(公式 + Pyramid 实例)

设 Stage1/DepGraph 切出:剪枝分区 $N_p$ 个(第 i 个有 $|W_i|$ 宽度档)、量化分区 $N_q$ 个(第 j 个有 $|Q_j|$ 精度档)。

$$
|\Theta_{sw}| \;=\; \prod_{i=1}^{N_p}|W_i|\;\times\;\prod_{j=1}^{N_q}|Q_j|
\;\xrightarrow{\text{均匀}}\; |W|^{\,N_p}\cdot|Q|^{\,N_q}
$$

- **单分区内**: 选 (宽度, 精度) 是**线性小菜单**($|W|\cdot|Q|$ 组合) —— "剪枝×量化这部分线性"。
- **跨分区**: 各分区独立取值 → 连乘 → **在分区数 $N_p,N_q$ 上是指数** —— "在分区上是指数的"。
- schedule 轴 s 条件化于 (p,q), **不进外层枚举**(内层 MetaSchedule 处理), 否则再叠一层指数。

**本阶段锁定实例**(用户拍板: **量化全局单精度** → $N_q=1,|Q|=3$; **剪枝 3-stage 粗分区** → $N_p=3,|W|=7$):
$$
|\Theta_{sw}| = |W|^{N_p}\cdot|Q|^{N_q} = 7^{3}\cdot 3^{1} = 343\times 3 = \mathbf{1029}
$$
对比: 整网单一剪枝率×单一精度(非分区) = 21(线性)。**指数来自 3 个 stage 的独立宽度组合($7^3$)。**

### 2.1 分区粒度决策(用户已拍板: 本阶段锁 3-stage 粗分区)
| 粒度 | $N_p$ | 剪枝空间 $7^{N_p}$ | ×3精度 | 冷启动数据 |
|---|---|---|---|---|
| **3 stage(本阶段采用)** | 3 | 343 | **1029** | original60 已覆盖, 零补 |
| ~per-block | ~9 | $7^9\approx4\!\times\!10^7$ | ~1.2 亿 | 须按细维重采(指数级) |

**为何锁粗分区**: ① 细分区指数爆炸 + 冷启动数据需求指数增长; ② AP 高原 + 延迟近单调于各 stage 总通道 → 细粒度通道再分配对 AP/latency 是二阶效应, 增益大概率边际; ③ original60 冷启动已覆盖 3-stage。若 3-stage Pareto 不理想再议细分区。
- **混合精度暂不做**(无实测数据); 量化 = 整网单精度 ∈ {fp32,fp16,int8}。

### 已有数据资产
- original60: 60 宽度 × 3 精度 = 180 cells, latency/energy/AP 已 180/180 整网真测(阶段二冻结) → 外层 cost model 训练/校准样本。
- 未测搜索区 = $|\Theta_{sw}|$ − 已测 = $1029 - 180 = \mathbf{849}$ 个未测联合配置(= 283 未测宽度 × 3 精度), 靠 surrogate 预测 + SMBO 真测 Top-K 覆盖。

## 4. 实验实施计划(分阶段, 待审)

> 原则: 真测就是真测; 每步可复现; 先小 smoke 再放量; H800 一卡一进程用空闲卡; lightgbm 必须单线程; 全栈 TVM。

### P2.0 空间落地(先做, 低成本, 无 GPU)
1. 用 `stage1_bridge.py` 对 Pyramid+H800 产出 Θ_sw: 确定 $N_p,N_q,|W|,|Q|$ + 合法性(ψ_hw int8 可 build / ψ_group grouped-conv) + 可分离性。
2. 确认现有 latency/energy 标签 = original60 整网真测(合法), 直接用, **不重测**。
3. 产出: `space_manifest_pyramid_h800_v1.json`(Θ_sw 枚举/合法过滤/规模统计, 核实 §2 公式实际值)。

### P2.1 内层 MetaSchedule 真测接口 + feasibility(打基础)
1. 封装可复现入口: 给定新配置 (p,q) → 导出整网 → TVM MetaSchedule 调 schedule → 实测 (lat_p50, energy)。
   - 先 2-3 个 original60 内配置做 smoke(验证接口 + 与已存实测值对齐, 校准口径 `latency_kind`)。
2. feasibility 二分类器: 用已有 build_success / AP_crash 记录训练(如 frontier_01 崩点)。
3. 产出: `measure_config.py`(整网真测接口) + feasibility 分类器。

### P2.2 外环 NSGA-II 三目标 + SMBO 闭环 smoke(真闭环, 主戏)
1. NSGA-II over Θ_sw 未测区, 3 目标(f_ΔAP 排序, f_lat, f_energy)预测 + feasibility 门 → 非支配排序。
2. 选 Top-K(前沿邻域×高不确定, K=6-8)**新联合配置**(original60 之外)。
3. **真测回灌**:
   - latency/energy: P2.1 接口整网真调优+实测(每候选廉价, 分钟级)。
   - AP: 冷启动复用 original60 的 60 个 AP 锚点(不重测); 闭环内 AP 走 **ΔAP 残差预测排序**(不 finetune); 仅对**每轮 Pareto 前沿的 Top-K 候选**做真 finetune 验证。
   - **AP finetune 预算(本阶段)**: finetune 上限 **31 epoch**(与现有实验标准一致)+ 1789 帧真测。真测锚点数按空间/候选规模定: 每轮 SMBO 选 **K=6** 候选, 跑 **≤3 轮** → 新增 **≤18 个** 31-epoch AP 锚点(占 849 未测区 ~2%, 够校准前沿又不爆 GPU-时)。中途排序若需可选早停 finetune(≤8 epoch)少量补充。
4. 回灌重训 cost model → 看留出候选预测误差下降 + Pareto 前沿推进。
5. 产出: 一轮真闭环证据(预测 vs 实测对比 + 前沿更新 + 模型改善曲线)。

### P2.3 三臂消融 Gap1(证联合价值)
S0(默认调度)/S1(串行 先剪后调)/S2(联合 P×Q×S)同预算比 Pareto HV, 证联合找到串行错过的点。对接 `run_pqs_ablation.py`。

### 停止点
P2.2 拿到"一轮真闭环: 预测→真测→回灌→模型/前沿改善"可复现证据 = 最小成功; P2.3 出三臂消融 = 论文级证据。

## 5. 关键决策(用户已拍板, 冻结)
1. **量化轴**: **全局单精度** ∈ {fp32,fp16,int8}($N_q=1,|Q|=3$)。混合精度暂不做(无实测数据)。
2. **分区粒度**: **3-stage 粗分区**($N_p=3$)。细分区(per-block 等)指数爆炸 + 需指数级补冷启动 + 增益大概率边际(AP 高原/延迟近单调), 本阶段不做; 3-stage Pareto 不理想再议。→ $|\Theta_{sw}|=1029$, 未测 849。
3. **AP finetune 预算**: 上限 **31 epoch** + 1789 真测; 复用 60 冷启动锚点; 闭环内 ΔAP 残差排序, 仅前沿 Top-K 真 finetune; 每轮 K=6 × ≤3 轮 = **≤18 个新 31-epoch 锚点**。
4. **本阶段范围**: **仅 Pyramid + H800** 单模型单硬件。跨硬件(Orin)/多模型(CoDriving)后续再议。

→ 决策已冻结, 下一步从 **P2.0**(stage1_bridge 落地 Θ_sw + 核实 $N_p,|W|$ 实际值)开始。
