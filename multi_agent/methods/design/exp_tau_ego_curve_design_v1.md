# 实验设计: τ_ego → V2X 场景驾驶分退化曲线 (exp_tau_ego_curve_v1)

> 作者: team-lead, 2026-06-11。目标 = 一张折线图: 横轴推理延迟 τ_ego, 纵轴驾驶分(+碰撞率), 展示延迟对 V2X 场景安全的渐进影响 + 一段机理解释。
> 依据: I-2 τ_ego 注入已实装(V2Xverse commit f63e92b); 全量 te219 扫描已定 23 行人+23 车辆交互路线; 单路噪声大、需大库聚合(详见本文 §6 反思)。

---

## §0 一句话方法论 (为什么这样设计)

单条路线 n=1 时 DS 被"恰好 1 次碰撞"的随机洗牌主导(±噪声), 看不出 τ_ego 单调性。**解法 = 在一个按场景类型选出的、无偏的大路线库(~60-70 条)上扫延迟梯度, 用聚合均值 DS + 碰撞率消掉单路噪声**, 让系统性的 τ_ego 效应从噪声里浮现。聚合是把"洗牌噪声"变成"碰撞概率"的唯一途径。

---

## §1 场景库构建 (★按类型推测, 非实测筛选)

**原则**: 不用"te219 碰了才选"(=实测, 有选择偏差), 而用**场景类型先验**: 行人横穿 + 路口车辆冲突 + 路口拐弯 = 默认 V2X 需求高的场景。这样库是无偏的, 聚合曲线才有说服力。

**Town05-short 现状** (105 条全 Town05, lb-v1, Scenario1/3/4 密集触发):
- Scenario3 = 动态障碍横穿(行人/自行车) ← V2X 核心(遮挡 VRU)
- Scenario4 = 路口车辆冲突 ← V2X 核心(遮挡来车)
- 路口拐弯 = 路线几何含交叉口转向

**库选择方法 (供 runner 执行, 二选一或叠加)**:
1. **几何先验**(首选, 真正"按类型"): 解析 route XML 的 waypoint, 选含**交叉口/转向**(yaw 变化 >45° 或经过 Town05 已知路口坐标)的路线 → 这些结构上保证遇路口场景。
2. **场景密度先验**: Town05 触发点密集, 几乎所有非平凡路线都遇行人/车辆; 故库 = 全 105 减去"双端都 DS≥99 无任何场景"的纯空路线(~? 条)。
3. **目标规模 60-70 条**: 若几何先验不足 70, 用密度先验补齐。**保留少量"易"路线作对照**(证明不是所有路线都退化)。

> ★ 关键纪律: 库一旦定下就**冻结**, 所有 τ_ego 档跑同一库, 配对比较。库定义写入 `scenario_library_v1.txt` (route id 列表 + 每条的几何/类型标注)。

## §2 延迟梯度 (自变量)

τ_ego ∈ **{0, 50, 100, 150, 200, 250, 300, 350, 400, 450, 500} ms** → Δ_ego = ceil(τ/50) ∈ {0,1,...,10}。
- τ_ego=0 = baseline 对照(理想无延迟机)。
- 真实加速档锚点(Orin 实测, 标注在图上): FP32 219 / FP16 136 / INT8 108。
- **可行性裁剪**: 若算力紧, 先跑 {0,100,200,300,400,500}(6 档) 出粗曲线, 再插值补 {50,150,...}。

---

## §3 指标 (因变量)

| 指标 | 定义 | 为什么 |
|------|------|--------|
| **mean DS** | 库内所有路线 score_composed 均值 | 主曲线纵轴 |
| **★碰撞率** | 出现行人/车辆碰撞的路线占比 | 最直接体现"碰撞概率随延迟增加"(用户要的) |
| mean RC | 路线完成度均值 | 区分"撞了但跑完"vs"卡死" |
| 行人/车辆碰撞分解 | 各类碰撞的路线数 | 看 τ_ego 主要伤哪类(预期: 行人为主, 走刹车路径) |
| 95% 置信区间 | 各档 DS 的 mean ± 1.96·SE | 判断档间差异是否显著(>噪声) |

★ 真相源 = 每条 `ego_vehicle_0/results.json`(非 CSV, CSV 会被脚本 truncate)。

## §4 多 Agent 协作设计

### Agent 1 — `exp-runner` (跑实验, sim-integrator 类型)
职责:
- 读 `scenario_library_v1.txt` + 延迟档列表, 生成 (route × τ_ego) 任务矩阵。
- 管理 CARLA 生命周期 / GPU 分配 / **端口宽间隔(≥100, TM_PORT=PORT+5 必须不撞邻居)** / 失败重试。
- 每个 τ_ego 档一套 config(`pnp_config_codriving_te{TAU}_l1.yaml`, 已有 te0/108/136/219, 需补 50/150/200/250/300/350/400/450/500)。
- 跑前 `nvidia-smi` 确认卡空; `setsid nohup` 起; 跑完清 CARLA。
- 结果落 `results/tau_curve/results_te{TAU}_r{route}.json` 索引 + 汇总 parquet。
- **启动后立即自检**: 确认越过第一条路线真出结果(防静默崩, 见 §6 教训)。

### Agent 2 — `exp-supervisor` (监督 + 反思, supervisor 类型)
职责:
- 每批结果到位后, 聚合**各 τ_ego 档的 mean DS + 碰撞率 + CI**。
- **核验是否符合预期**: DS 随 τ_ego 单调降? 碰撞率单调升? 档间差异 > CI?
- **不符合预期时诊断**(按序查):
  1. 机制是否生效? grep 日志 `Δ_ego=N frames` 确认延迟真施加。
  2. 洗牌噪声? 看单档内路线方差; 若大 → 要求 runner 加 n 重复(n=3→5)。
  3. 库太易(全 DS≈100)或太难(全崩)? → 调库(§1)。
  4. 转向免疫(撞墙主导)? → 标记需 L1 纯追踪修法(见 `l1_fix_proposal_purepursuit_v1.md`)。
  5. 端口冲突/批量 ERR(像首轮 g3/g6)? → 查 rpc_error, 宽端口重跑。
- 落盘反思到 `tau_curve_supervisor_log.md`, 每轮结论 + 下一步指令给 runner。
- **对 runner 自报"已完成 N 条"必复核** results.json 实存(防谎报)。

### Agent 3 — `exp-analyst` (绘图 + 解释, 可选/可由 main 兼)
- 读汇总 parquet, 绘**折线图**: 横轴 τ_ego(ms, 可叠加"等效推理 FPS"次轴), 纵轴 mean DS + 碰撞率(双轴/双子图), 带 CI 误差棒, 标注 FP32/FP16/INT8 锚点。
- 写**机理解释段**: 为什么 DS 随延迟降(晚刹车→撞行人), 哪类场景最敏感, V2X 协同如何缓解。
- 图存 `multi_agent/figure/tau_ego_curve_v1.png` + 解释入设计文档。

### 协作流
```
main(orchestrator)
  → exp-runner: 跑 Phase1 pilot
  → exp-supervisor: 聚合+反思 pilot → 符合预期? 
       是 → 指令 runner 跑 Phase2 full
       否 → 诊断 → 调库/加n/修机制 → 重跑
  → exp-analyst: full 数据出图+解释
  → main: 核验图 + 落盘
```

## §5 执行阶段 (算力现实: 共享服务器, ~5-6 空卡浮动)

| 阶段 | 内容 | 规模 | 估时(6卡@~9min/route) |
|------|------|------|----------------------|
| **P0 建库** | 几何解析选 ~65 条 + 冻结 | — | <1h |

| **P1 反思** | supervisor 验趋势 | — | — |

## §6 预期结果 + 不符预期的检查 (★反思协议)

**预期**: mean DS 随 τ_ego **单调降**; 碰撞率随 τ_ego **单调升**(尤其行人碰撞)。机理 = 延迟↑→感知/规划滞后→晚刹车/晚避障→撞行人概率↑。

**已知风险与对策(supervisor 必查)**:
1. **聚合仍平**: 单路实测平均 Δ(te0→te219)≈ -1~-11(noisy)。靠**大库 + n 重复**把 SE 压到能分辨档间差。若 65 条 n=3 仍平 → 库选偏了(混入太多无场景路线)或机制只动速度不动转向(需纯追踪修法)。
2. **非单调/反向档**: 个别 τ_ego 档反弹 = 洗牌噪声未被 n 充分平均。加 n 或扩库。
3. **天花板/地板**: 若 baseline(τ=0)就低(库太难)或 τ=500 仍高(库太易) → 动态范围不足, 调库难度。
4. **碰撞类型**: 预期行人碰撞随 τ 升最明显(速度路径, I-2 已支持); 车辆碰撞噪声大。可主推**行人碰撞率 vs τ_ego** 作最干净子图。
