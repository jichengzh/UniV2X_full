# 方法（第二部分）· 阶段二：软硬件协同优化

## 3.2 阶段二：软硬件协同优化

为了在阶段一得到的合法配置空间中寻找有效部署方案，阶段二需要同时解决两个问题：其一，如何高效访问候选点；其二，如何快速评估已访问候选的部署质量。前者对应配置空间探索，后者对应多指标代价模型。受 ALT 中交叉探索思想的启发 \cite{xu2023alt}，我们将软件侧配置与硬件侧调度组织为嵌套搜索过程；同时，借鉴 CHaNAS 的块级预调度思想 \cite{shu2021chanas}，用内外双层预测器减少昂贵的设备测量与完整精度评测。

### 配置空间探索

阶段一已经将网络结构依赖和硬件可达性压缩为合法配置集合 $\Theta$。一个候选点可写为
$
c=\langle x,s\rangle,\quad x\in\Theta,\ s\in\Sigma_{\mathrm{sch}}(x),
$
其中 $x$ 表示外层配置，$s$ 表示由该配置诱导的硬件调度。这里的关键并不是把所有配置与所有调度做笛卡尔积，而是承认调度空间依赖于外层配置：当外层配置改变时，通道宽度、数据格式、对齐关系和可融合边界随之改变，合法调度空间 $\Sigma_{\mathrm{sch}}(x)$ 也需要重新定义。这与 ALT 中“layout 改变后 loop 空间需要重建”的观察一致 \cite{xu2023alt}。

外层探索采用 NSGA-II \cite{deb2002nsga}。该算法是成熟的多目标进化搜索方法，能够在不预设权重的情况下维护一组非支配候选，适合处理离散配置、非光滑硬件响应以及精度、延迟和能耗之间的冲突。由于探索算法本身不是本文的主要贡献，我们仅将其作为外层候选生成器：每一代种群首先由阶段一给出的合法性约束过滤，然后交由代价模型快速评估；只有位于预测前沿附近或不确定性较高的少量候选会触发内层调度搜索和设备测量。搜索结束后，NSGA-II 输出的非支配集合构成阶段二的候选 Pareto 前沿。

### 多指标代价模型

直接评估一个候选点需要完成调度搜索、编译、硬件测量和精度评测。若对每个候选都执行这一流程，搜索代价将随配置数量线性增长而不可接受。因此，我们构建一个内外双层代价模型：内层模型服务于固定外层配置下的调度选择，外层模型服务于模型级候选的多指标预测。二者的关系与 ALT 的交叉探索结构相同：外层配置决定内层调度空间，内层调度结果再作为外层候选的性能反馈 \cite{xu2023alt}。

**内层调度预测器。** 给定外层配置 $x$，内层需要在 $\Sigma_{\mathrm{sch}}(x)$ 中寻找较优调度实现。我们复用 TVM 的自动调度预测器 \cite{chen2018tvm,chen2018learning}，用低层中间表示中的循环结构、访存表达式和算子调度特征对调度候选进行排序。与 ALT 只测量每个 batch 中预测 top-$k$ 点的做法类似 \cite{xu2023alt}，内层并不穷举所有调度，而是选择少量高潜力调度在目标硬件上测量，并用实测结果在线更新调度预测器。对外层而言，内层返回的是该配置下经调度后的块级延迟和能耗，而不是默认调度下的粗略估计。

**块级查找表。** 为避免外层每访问一个候选都重新运行完整内层搜索，我们借鉴 CHaNAS 的块级预调度思想 \cite{shu2021chanas}，将网络划分为若干计算块，并为每个块在不同外层配置条件下记录内层调度得到的最优实现及其硬件代价。记第 $b$ 个块的查表结果为
$
\mathcal{L}_b(x_b)=\langle s_b^\star,\ell_b,e_b\rangle,
$
其中 $x_b$ 是候选在该块上的局部配置，$s_b^\star$ 是内层选择的调度，$\ell_b$ 和 $e_b$ 分别表示块级延迟和能耗。这样，外层评估一个新候选时可以先查询 block LUT，而不是立即触发完整编译和测量。对于串行子图，块级代价可按执行顺序组合；对于存在并行分支、跨设备传输或融合边界的子图，组合函数由拓扑关系决定。我们将这一组合过程写为
$
(\ell_{\mathrm{lut}},e_{\mathrm{lut}})=\Phi_{\mathcal{T}}\big(\{\mathcal{L}_b(x_b)\}_{b=1}^{B}\big),
$
其中 $\mathcal{T}$ 表示候选对应的执行拓扑。该形式保留了 CHaNAS 中通过块级查表降低搜索成本的思想，同时避免把所有 V2X 子图都假设为简单串行加和。

**外层多指标预测器。** block LUT 提供局部硬件代价，但模型级延迟和能耗还受到跨块边界、数据搬移、调度组合和硬件状态的影响。因此，外层使用按模型和目标硬件训练的 LightGBM 预测器，将候选配置特征、块级 LUT 统计量和拓扑特征映射到模型级指标。设候选 $c$ 的指标向量为
$
\mathbf{m}(c)=\big(\mathrm{AP}(c),\ell(c),e(c)\big).
$
其中 $\ell$ 和 $e$ 分别表示模型级延迟与能耗。延迟和能耗具有较强的硬件响应，因此外层分别学习 $\hat{\ell}(c)$ 和 $\hat{e}(c)$；为了服务 Pareto 排序，模型同时关注绝对值预测和相对顺序。绝对值用于给出前沿坐标，相对顺序用于在同一模型和硬件条件下区分快慢与能耗高低。树模型适合这一任务，因为硬件性能常出现由对齐、融合或调度选择引起的非光滑跳变，而这些跳变难以用平滑回归模型刻画。

AP 的建模采用不同原则。与延迟和能耗相比，AP 对配置变化的响应更弱，并且受到训练收敛、数据集划分和评测噪声影响。因此，我们不把预测 AP 作为最终前沿上的精度值，而是学习相对于已测锚点的残差
$
\Delta\mathrm{AP}(c)=\mathrm{AP}(c)-\mathrm{AP}(c_0),
$
其中 $c_0$ 为基线配置或邻近已测配置。残差预测只用于搜索过程中的候选排序和粗筛，帮助外层搜索避免明显低精度区域；最终报告的 AP 必须来自统一评测协议下的真实测量。由此，代价模型在搜索阶段提供低成本反馈，但最终结论仍由硬件测量和精度评测支撑。

**测量回灌。** 在每一轮外层搜索中，代价模型首先对整个人群给出 $(\widehat{\mathrm{AP}},\hat{\ell},\hat{e})$ 及其不确定性估计。随后，搜索器选取预测前沿附近且不确定性较高的候选进行实测：硬件测量用于更新 block LUT、内层调度预测器和外层延迟/能耗预测器；AP 评测用于更新残差精度模型。这个闭环与 ALT 和 AutoTVM 中“预测 top-$k$、硬件测量、在线更新”的策略一致 \cite{xu2023alt,chen2018learning}，但扩展到多指标设置。最终，阶段二输出的不是单个最优点，而是一组非支配候选及其预测指标；其中代表性 Top-$K$ 配置进入完整编译、硬件测量和 AP 复核，用于形成最终实验结论。
