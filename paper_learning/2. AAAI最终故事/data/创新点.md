# Paper §C 创新点 — 用最少数据训出可用性能预测器

> **核心命题**: 在 V2X 协同检测的 B×Q×D×HW×Model 搜索空间上, 用 **K=32-64 个真实测量 anchor** (而非满笛卡尔 720+) 训出 R²≥0.9 的 lat / AP 预测器, **采集效率比 random sampling 高 3-5×**.
>
> 创新点不在 LGB 算法本身, 而在**采样设计 (DoE)** + **维度敏感性分解** + **active learning 闭环**, 让 paper §C 的"加速效果跟预测器是否覆盖搜索空间相关"这个命题有可证伪、可量化的实验支撑.
>
> 关联文档: `数据集制作_plan.md` §4.6, `dataset_analysis.md`, `问题.md`

---

## 1. 问题与现状

### 1.1 朴素方法的两个失败模式

**满笛卡尔积 (v1.2 时期 720 anchor 计划)**:
- 8 prune ratio × 10 quant variant × 4 deploy config × 2 HW × 3 model ≈ 1920 cell
- 单 anchor ~8 min (含 AP eval n=1789), 总成本 ~256 GPU-h
- 真实跑下来 (我们 v1.2 时代经验): 大量 cell **信息冗余** (Q 维度上 6 个 non-entropy 量化方式 AP 几乎相同) 或 **完全无效** (entropy 在 4/8 自训 ckpt 上崩, INT8 在 Orin 跨版本 cache 失败)

**随机均匀采样 (反思 #24 #28 推荐)**:
- 假设没有维度先验, 随机抽 K 个 anchor 训 LGB
- 在我们 224 anchor 的初步实验上: K=32 random 跑 lat 预测 R² ≈ 0.7-0.8 (波动大), AP 预测 R² ≈ 0.5 (entropy 崩点把方差吃满了)
- **问题**: 真实搜索空间各维度信息密度极不均, random 浪费 budget 在低信息密度维度上

### 1.2 我们的核心观察 (来自 224 真测 anchor)

在 e2e_bench_v1.csv 上做的事后分析 (`dataset_analysis.md` 综合反思) 揭示 **维度间信息密度严重不均**:

| 维度对 | 信息密度 | 经验证据 |
|--------|----------|----------|
| **AP × Q (除 entropy)** | **极低** | 6 个 Q (fp32/fp16/int8_mm/int8_pc_wo/mix_s0/mix_s2) 跨 8 triplet AP 全在 [0.528, 0.568] 4pp 窄带, std ≈ 0.012 |
| **AP × B (prune ratio)** | **极低** | Spearman r=-0.21, p=0.61, 实测 e2e 管线下 0-75% prune AP 几乎 flat |
| **AP × Q_entropy** | **极高** | 16/32 anchor 崩到 0.14-0.27, 强 ckpt_source × Q=entropy 耦合 |
| **lat × (B, Q, D)** | **高** | throughput_fps 跨 (B, Q, D) 范围 53-154 fps (~3× span), 强 B×Q (ResNeXt grouped conv) 与 Q×D (Q_int8_pc_wo + tactic) 耦合 |
| **lat × workspace** | **中** | 1-16GB workspace 跨 (T, Q) 单调性弱, fps_delta_pct 在 [-23%, +14%] |

→ **理性的采样不应均匀分配 budget**. 应该:
- AP 头: 只需小量样本校 entropy crash boundary + non-entropy 4pp 噪声地板
- Lat 头: 大头采样需投在 (B × Q) 耦合区域 + (Q × D) 高方差区域

## 2. 方法论 — Sensitivity-stratified DoE + Active Learning

> Stage 命名与 `数据集制作_plan.md` §5 完全对齐.

整体框架是 4 个 Stage:

```
Stage 1 (方法论验证, 0 新数据):
  1a: sampling efficiency study      ← 224 已测 anchor 当 ground truth
  1b: active learning loop           ← predictor uncertainty 选下一批
  1c: sub-predictor decomposition    ← f_lat / f_AP_baseline / f_AP_crash 三分解
Stage 2 (Pyramid 数据集补全):
  2a: A.1 phase2 pt 变体 (+24 anchor)
  2b: A.3 Orin 跨硬件 (+250 anchor)
  2c: B/C class D-space (+290 anchor)
Stage 3 (跨模型 transfer): V2X HEAL baseline 各 16 anchor (+48)
Stage 4 (LGB 重训 + Pareto demo)
```

### 2.1 Stage 1a — 离线 sampling efficiency study (0 新数据)

**实验设计**: 用现有 224 anchor 当 ground truth, 抽 K 个 anchor 训 LGB, 在 (224-K) 上评估.

**对比 sampling 策略**:

| 策略 | 实现 | 期望表现 |
|------|------|----------|
| **Random** | uniform 随机抽 K | 基线, K=32 R² ≈ 0.7 |
| **Latin Hypercube (LHS)** | 每维度 K 个分位等距点, 不重复 | K=32 R² ≈ 0.75-0.8 |
| **Sobol low-discrepancy** | Sobol 序列在 (B, Q, D) 上低差异采样 | K=32 R² ≈ 0.8 |
| **Sensitivity-stratified (我们)** | pilot K=8 跑出 per-dim variance, 用 variance 加权分配剩余 budget. 高方差维度 (Q × D 耦合) 多采, 低方差维度 (AP × Q_non_entropy) 少采 | **K=32 R² ≥ 0.85, K=64 R² ≥ 0.9** |

**评估矩阵**: 4 sampling × 6 K size {16, 32, 48, 64, 96, 128} × 5 repeat = **120 LGB 训练**. 每次 ~5 sec, 总 ~10 min CPU.

**产出**:
- **主图 A**: K-R² 曲线 (4 sampling 各一根), 显示 sensitivity-stratified 比 random 在 K=32-64 区间高 0.1-0.2 R²
- **主图 B**: 4 sampling 在 K=32 下的 hold-out AP/lat residual 散点, 显示 entropy crash 区是 random/LHS/Sobol 通病, sensitivity-stratified 主动加密 entropy 边界

### 2.2 Stage 1b — Active learning loop (0 新数据, 用 224 当 oracle)

**算法**:

```
1. seed = sensitivity-stratified(K=32) 训 LGB lat/AP 预测器
2. for round in 1..8:
3.   predict 全 224 cell, 取 LGB leaf-variance 作 uncertainty
4.   选 top-8 uncertainty cell 加入训练集 (K += 8)
5.   重训预测器, 记 R² on (224-K) hold-out
6. 输出 K-R² 曲线 (with vs without active)
```

**核心 claim**: active 在 K=48 处就追上 static sensitivity-stratified K=64 的 R².

**产出**: 主图 C — active vs static 收敛速度对比, 横轴 K, 纵轴 R².

### 2.3 Stage 1c — 维度敏感性可分解 (可解释性 + 跨模型 transfer 桥梁)

训 3 个独立子预测器 (用 224 oracle 验证可分解性):

| 子预测器 | 输入 | 输出 | 目标 R² |
|----------|------|------|---------|
| **f_lat (B, Q, D)** | 11 维坐标 | throughput_fps | ≥ 0.92 |
| **f_AP_baseline (B, ckpt_source)** | prune ratio + 是否官方 ckpt | AP50 的中位数 (0.53-0.57 区间) | ≥ 0.85 |
| **f_AP_crash (Q, ckpt_source)** | Q_tag + ckpt_source | binary {crashed: AP<0.4, healthy: AP≥0.4} | AUC ≥ 0.95 |

**意义**:
- 证 AP 不需要 D 维度采样 (f_AP_baseline 不需要 D), Orin 上**不必跑 AP eval** 的理论支撑
- 证 f_AP_crash 是 binary classifier, 只需 K=8-16 anchor 校 entropy boundary
- f_lat 是 paper §C 主表数据需求大头

**产出**: 主图 D — per-dim Shapley importance 直方图, 显示 D 维度对 AP 贡献 ≈ 0, B 维度对 AP 贡献低 (~1pp), Q 维度对 AP 贡献集中在 entropy 一个 bin 上.

### 2.4 Stage 3 — 跨模型 transfer (Stage 2 之后, 真采新数据)

**Claim**: Pyramid 224 anchor 训的 f_lat / f_AP_crash 在新 V2X HEAL baseline (F-Cooper / AttFuse / V2X-ViT) 上, 每个 baseline 只需 **K=16 calibration anchor** 即可达 R²≥0.85.

**机制**: shared (B, Q, D) 编码 + per-model bias term (model embedding ∈ R^8).

**数据需求**: 3 新模型 × 16 anchor (4 prune × 4 Q × 1 D) = **48 anchor**, ~6h 4090 单卡.

(对应 Stage 2a/2b/2c 是 Pyramid 数据集补全, 不在创新点核心闭环中, 详见 `数据集制作_plan.md` §5)

## 3. 方法论的 paper §C 故事化

### 3.1 一句话定调 (写进 abstract / intro)

> "We propose a sensitivity-stratified design-of-experiments framework for performance predictor training on V2X co-perception search spaces. Our method achieves R²≥0.9 latency / R²≥0.85 AP prediction with **K=64 measured anchors**, compared to **K=224 random** required for the same accuracy — a **3.5× sampling efficiency gain**."

### 3.2 paper §C 主图 layout

```
Figure 3 (4-panel composite):
  (a) K-R² curve, 4 sampling strategies × 6 K size, lat predictor
  (b) K-R² curve, AP predictor (with entropy boundary inset)
  (c) Active vs static convergence, K=32→96
  (d) Per-dim Shapley importance, lat / AP / crash binary
```

### 3.3 anti-pattern + reflection (诚实 caveat)

- **Limitation 1**: 224 anchor 仅覆盖 Pyramid 一个模型, V2X baseline transfer 是 K=48 (小样本) 验证, 不是大规模
- **Limitation 2**: e2e AP 在 Q 维度 flat 是 DAIR-V2X 数据集的特点 (NMS + post-process 噪声占主导), OPV2V / cooperative dataset 上可能不同
- **Limitation 3**: Phase α 用 224 当 oracle, 但 224 自身覆盖率仍仅 0.5% (4090 搜索空间), 预测器在未采样区域 (e.g., D2/D3 workspace × Q_int8_pc_wo) 外推风险

## 5. 风险与备选

| 风险 | 表现 | 应对 |
|------|------|------|
| Stage 1a 显示 4 sampling 区分不显著 | K-R² 4 条曲线粘成一团 | 改 "data-efficient predictor on 224 hard-won anchor" 叙事, 砍 sampling 创新点, 主推数据集 + 跨模型 + 跨硬件 generality |
| 224 数据本身不足以训 R²≥0.9 lat 预测器 | K=128 random 仍 R²<0.85 | 说明 e2e_bench_v1 还需要补 (Stage 2c B.4 random_search unseen triplet 48 anchor) |
| Stage 1c 子预测器分解失败 (f_AP 仍需 D 维度) | f_AP excluding D 比 full feature R² 显著低 | 接受 "AP 跨 D-config 不变" 假设错, 写进 reflection, 但不影响 Stage 1a+1b 主 claim |
| Stage 3 V2X baseline ONNX export 失败 | F-Cooper / AttFuse fusion_net 不兼容 ONNX | 替换 V2X-ViT 为 baseline transfer 唯一对象, 加 OPV2V Pyramid (有 HF ckpt) 补 |
| Stage 2b Orin 解锁失败 | TRT cache patch 无效 | 撤回跨硬件 claim, 仅做 4090 内的 sampling 创新点, 数据规模 ~272 anchor (224 + 48 跨模型) |
