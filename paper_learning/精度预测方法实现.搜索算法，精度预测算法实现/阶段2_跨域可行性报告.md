## 二、关键发现

### 2.1 架构不兼容 — 完整 inference 路径 X 直接死

**UniAD-tiny 的 BEVFormer 硬编码 6 cam**:
```python
# from uniad_tiny_b2d.pth state_dict
pts_bbox_head.transformer.cams_embeds.shape == (6, 256)   # 6 个相机 embedding
```

**V2X-Seq-SPD 车端只有 1 cam**:
```python
# from spd_infos_temporal_val.pkl
sample['cams'] == {'VEHICLE_CAM_FRONT': {...}}   # 1 个相机
```

**结论**:
- BEVFormer 的 spatial cross-attention 数学结构依赖 `(B, 6, C, H, W)` 输入
- 1 cam 跑 6 cam 网络:用 dummy / 复制特征填补,精度衰减必然 > 80%
- 不是 DataLoader 能修复的差异,**等价于路径 Z 重训**

→ **D2.5 直接判定 mAP 衰减 > 70%,走路径 Z 或 Y**(D2.5.1 默认推荐升级到下一级)

### 2.2 R50 backbone 可独立迁移 — 路径 Y 比预期更可行

跑了 3 张 SPD 车端图像的最小实验(`scripts/phase2/cross_domain_backbone_test.py`):

| 检查项 | 结果 |
|-------|------|
| backbone 权重加载 | 318/318 keys ✓ (missing 仅 fc) |
| layer1-4 输出 shape | 完全符合期望(800×450 → layer4 15×25) |
| 数值合理性(mean/std) | mean ∈ [+0.02, +0.06], std ∈ [0.03, 0.11] |
| NaN / Inf | 0 / 0 |
| 零值占比 | 51% (标准 ReLU 激活率) |
| **总评分** | **12/12 OK = 100%** |

**详细数据**(以 002879.jpg 为例):
```
layer1: shape=[1, 256, 113, 200] mean=+0.053 std=0.094 zero%=51.7%  OK
layer2: shape=[1, 512,  57, 100] mean=+0.038 std=0.067 zero%=49.9%  OK
layer3: shape=[1,1024,  29,  50] mean=+0.027 std=0.048 zero%=50.8%  OK
layer4: shape=[1,2048,  15,  25] mean=+0.018 std=0.033 zero%=51.2%  OK
```

**这证明了**:
- UniAD-tiny 的 R50 backbone 在 SPD 真实路侧图像上**能正常工作**
- 没有 NaN / 全 0 / 退化
- 即使 SPD 图像分辨率(1920×1080)和域(真实路况)与 b2d(800×450 CARLA)不同,backbone 仍能产生合理特征

## 三、路径决策 — 选定路径 Y(半监督迁移)

### 三条候选路径回顾

| 路径 | 描述 | 适用条件 | 我们的情况 |
|------|------|---------|-----------|
| X 零样本 | 直接拿 UniAD-tiny 权重在 SPD 上推理 | 衰减 < 30% | ❌ 架构不兼容,无法跑 |
| **Y 半监督迁移** | 借 UniAD-tiny 的 R50+部分权重作初始化,重训 V2X 协同 + heads | 衰减 30-70%(此情况架构兼容部分) | **✓ 最佳选择** |
| Z 全重训 | mirror UniAD-tiny 简化策略,从 ImageNet 完全重训 | 衰减 > 70% / 路径 Y 失败 | 备选 |

### 路径 Y 的具体方案

```
UniAD-tiny 权重(b2d 训出):
├── img_backbone (R50)         ← 100% 跨域合格,直接借
├── img_neck (FPN)              ← 跟着 backbone 一起借
├── pts_bbox_head.transformer  ← 部分借 (剔除 cams_embeds 等 6 cam 相关)
│   ├── encoder.layers          ← BEV self-attention 借,cross-attention 重训
│   ├── decoder.layers          ← 借
│   ├── cams_embeds (6, 256)    ← ❌ 不能借,SPD 只 1 cam
│   └── ...
├── memory_bank                ← 借
├── motion_head / occ_head     ← UniV2X 不需要这些,删
└── seg_head                   ← UniV2X 用自己的,不借

                               ↓

UniV2X-tiny (新训):
├── img_backbone (R50)         ← 借自 UniAD-tiny ✓
├── img_neck (FPN)              ← 借自 UniAD-tiny ✓
├── ego BEVFormer (1 cam)       ← 重训,改 num_cams=1, cams_embeds 重新随机初始化
├── infra BEVFormer             ← 重训(SPD infrastructure-side 也是 1 cam)
├── Cross-Agent Fusion          ← 重训(V2X 协同,UniAD 完全没有)
├── Track head (V2X 协同)       ← 重训
└── Seg head (V2X 协同)         ← 重训
```

### 预期收益
- vs 路径 Z(全重训): **节省 ~50% 训练时间**(R50 已经收敛过,不需要从 ImageNet 重学)
- vs UniV2X-base(R101+DCN): backbone 可剪 90.3%(L2 已证),论文卖点充足
